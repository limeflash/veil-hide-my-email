# Veil icons

All icons except the logo are inline SVG on a 24×24 viewBox, drawn with `stroke="currentColor"`, no fill, round caps and joins, stroke width 1.5, one size (16px) —
the Lucide style that Astryx’s Neutral theme uses. Paths marked **Lucide** are copied or lightly adapted from [Lucide](https://lucide.dev) (ISC licence);
paths marked **original** were drawn for Veil.

In the handoff HTML the presentation attributes come from CSS (`.v-icon` in `components.css`, `.veil-icon` in `inpage.css`),
so the markup is just `<svg class="v-icon" viewBox="0 0 24 24" aria-hidden="true">…</svg>`. The snippets below carry the
attributes explicitly so each one also works on its own. Sizes: `.v-icon` and `.v-icon--sm` 16px, `.v-icon--xl` 24px (empty states only). Icons take the colour of their text role.
Icon-only buttons need an `aria-label`; decorative icons keep `aria-hidden="true"`.

34 icons.
